# Licenciamento de assets e distribuição

## Status atual

Este repositório inclui sprites, tiles, interfaces e efeitos em `assets/`, além de metadados auxiliares em `assets/spritesheet/` e `assets/tilesheet/`.

Os arquivos distribuídos no projeto foram enviados como parte do pacote de assets do protótipo e não contêm, no próprio repositório, uma declaração explícita de licença por arquivo.

## Política de uso

- O uso atual neste projeto é para demonstração, avaliação técnica e desenvolvimento local.
- A redistribuição pública deste repositório deve considerar a licença original de cada asset antes de qualquer uso comercial ou de distribuição externa.
- Se o projeto for publicado em produção, é recomendável substituir os assets sem licença explícita por materiais com atribuição e licença compatível.

## Arquivos relevantes

- `assets/`
- `assets/spritesheet/`
- `assets/tilesheet/`

## Observação

Este repositório não declara uma licença de código ou de mídia para todos os ativos. Portanto, o correto é tratar os recursos visuais como assets internos de desenvolvimento até que a origem e os direitos do material sejam verificados.

Antes de lançar uma versão pública ou comercial, revisar a procedência dos sprites e confirmar se a licença permite uso, modificação e redistribuição.
